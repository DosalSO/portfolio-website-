Project Overview and Update:
Our project, titled "College Hub Bulletin Board System," is a dynamic and user-friendly
web platform designed to streamline communication, announcements, resources, 
and support services within a college community. The system has progressed
significantly since its initial proposal, incorporating real-time announcements,
user authentication, multilingual support, accessibility tools, and chatbot assistance 
aligned with Sustainable Development Goal (SDG) 4 – Quality Education.

This platform serves as a centralized digital bulletin board where students,
faculty, and administrators can interact effectively. The project
uses the MVC architecture — with MySQL handling the model (data), 
React.js managing the view (user interface), and Node.js with Express.js
acting as the controller (business logic).
